# 数据目录

把你的化工安全规程 PDF 放在这里，文件名任意（脚本会读 `data/*.pdf`）。

## 去哪找（按可用性排序）

1. **国家标准全文公开系统** https://openstd.samr.gov.cn —— GB 标准可在线阅读/下载
2. **应急管理部** https://www.mem.gov.cn —— 规章、事故调查报告、安全作业规范
3. **《危险化学品安全管理条例》** 等公开法规文本
4. 学校图书馆的化工安全教材（仅本地使用）
5. 企业公开的《安全操作规程》模板

## 两个红线

- 不要使用涉密文件或企业内部资料
- 不要把受版权保护的 PDF 提交到 GitHub

`index/` 和 `data/*.pdf` 已经在 `.gitignore` 里，不会被误传。
为了让别人能复现，建议自己整理 3–5 页示例放到 `data/sample.md`，说明输入长什么样。
